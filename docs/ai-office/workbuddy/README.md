# WorkBuddy 实战系列：普通人的 AI 同事上手指南

> 面向各行各业非技术普通人的 WorkBuddy 实战系列，规划 38 篇，按「机制、场景、身份」三层递进。已发布 1 篇，持续更新。

本系列不复制官方功能说明书，也不做案例集锦。它回答一个具体问题：**一个不懂技术的普通人，怎么把 WorkBuddy 用成真能干活的 AI 同事？边界在哪里，账怎么算？**

## 系列定位

- **写给普通人**：不出现任何开发者场景，不讲代码，不要求技术背景。
- **机制打底**：先讲清它怎么工作，再谈场景怎么用，不背功能清单。
- **评测视角**：官方说能做的和实测做到的分开写，每篇交代边界和不该用的场合。

## 必读主线

第 1 篇心智模型 → 第 2 篇第一个任务 → 第 3 篇任务生命周期 → 第 4 篇指令与验收 → 第 6 篇四机制决策树。这五篇读完，其余篇目按需跳读。标 ⭐ 的是核心篇目（共 12 篇）。
